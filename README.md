# Auto_Tracking_Turret_ME230
## A Mechtronics Project for ME 230
### by Henry Cechini and Madi D'Elia

Key Goals:
 * Track the nearest object using a rotating LiDar turret
 * Lock on to tracked target with foam dart turret
 * manual override with IR remote
 * warn intruder using sounds and lights to exit the secured zone
 * launch dart at target if they don't leave the restricted zone
